- `docs/MEMOH_API_COVERAGE.md` 记录 **338** 个服务端操作。

## F. 明确不做

| 端点 | 原因 |
|---|---|
| `POST /bots/{id}/mcp-stdio` | 服务端启动子进程，移动端无生命周期 |
| `GET /bots/{id}/web/stream` | 网页侧 SSE，原生走 WebSocket |
| `GET /oauth/mcp/callback`、`/providers/oauth/callback` | 浏览器回跳页 |
| `POST /bots/{id}/tools` | 统一工具网关，属内部调用 |
| `webhook-tunnel` | 需要公网回调地址 |

## 建议顺序

1. **B 供应商 + 模型管理** —— 不做它，新设备装完 App 走不完「配好就能聊」
2. **C 用量 + 账号资料** —— 日常最常看的两屏
3. **D 容器启停 + 依赖管理** —— Bot 报错时唯一自救手段
4. **A TTS + 技能目录** —— 聊天体验增益
5. **E 远程桌面** —— 成本最高，收益最不确定

只勾 ✅ 的项代表代码路径存在；**没有一项在真机上验证过**（`adb devices` 始终为空）。
