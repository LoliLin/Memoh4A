# Memoh 客户端功能对齐清单

> 对齐对象：固定版本的开源 Memoh 网页控制台与本地 Swift 客户端 Homem（`reference/homem`）。
> 本文件是功能入口清单，不是完整性或真机可用性报告。只有 API 封装、没有可达界面的功能记为未接入。

**2026-10-27 更新**：供应商、模型列表、用量和账号页面已有入口；用户指定移除的快捷栏入口已从清单状态中扣除。聊天模型新增及连通性测试已有入口；模型高级配置编辑、用量配额等仍未完成。初次审计的脚本计数只能作为粗略盘点，不代表已验证覆盖率。

图例：`✅ 有入口` ／ `🟡 部分入口` ／ `⬜ 无入口` ／ `— 移动端不适用`。`✅` 不代表真实服务器及真机验证通过。

## 建议顺序

1. **B 供应商 + 模型管理** —— 不做它，新设备装完 App 走不完「配好就能聊」
2. **C 用量 + 账号资料** —— 日常最常看的两屏
3. **D 容器启停 + 依赖管理** —— Bot 报错时唯一自救手段
4. **A TTS + 技能目录** —— 聊天体验增益
5. **E 远程桌面** —— 成本最高，收益最不确定

只勾 ✅ 的项代表代码路径存在；**没有一项在真机上验证过**（`adb devices` 始终为空）。
